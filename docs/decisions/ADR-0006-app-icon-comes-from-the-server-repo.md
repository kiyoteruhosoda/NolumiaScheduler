# ADR-0006: アプリのアイコンはサーバーのリポジトリの生成スクリプトから作る

- 状態: 承認
- 日付: 2026-10-20
- 関連: task #548、サーバー（forge `kyon/nolumiascheduler-server`）の ADR-0057

## 文脈

`NolumiaScheduler.WinUI/Assets/app.ico` は青いカレンダーで、WBS・Tracker と同じ青だった。持ち主（2026-10-20）が 3 つの見た目を
見分けられるようにしたいと言い、Scheduler は紫のカレンダーに決まった（サーバーの ADR-0057）。

## 決定

1. `app.ico` は**サーバーのリポジトリの `scripts/generate_pwa_icons.py --ico`** で作る（紫の角丸に白いカレンダー、今日のますだけ黄色。
   256・48・32・16）。Web の Scheduler と同じ絵・同じ色になる。
2. このリポジトリには出力の `app.ico` だけを置き、手で描き直さない。絵や色を変えるときはサーバー側を直して出し直す。

## 影響

- 窓・タスクバー・通知領域・実行ファイルのアイコンが変わる（どれも `app.ico` を読む）。
